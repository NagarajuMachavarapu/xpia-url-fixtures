A frame starts with an unsigned 16-bit big-endian payload length followed by that many UTF-8 bytes. The maximum payload is 4096 bytes; reject larger lengths before allocating a payload buffer. A request payload PING receives a response payload PONG. An incomplete frame fails on timeout or cancellation without emitting partial application data.
